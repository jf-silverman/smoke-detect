# Phase C — in-distribution fine-tuning (findings)

**Status: first result, directional (n = 6 held-out fires).** Phase C tests the project's central
hypothesis: the recent-California miss is *distribution shift*, and the fix is training on Californian
smoke. We fine-tuned the pyro-sdis @1280 detector on our own hand-corrected FIgLib boxes and measured
it on 6 recent CA fires held out at the whole-fire level.

## What was trained

- **Base model**: `gcp_grouped_1280` — the full-scale pyro-sdis YOLO11n @1280 (French towers).
- **Fine-tune data**: the [corrected day-only set](data-quality-flags.md) — 17 FIgLib fires, 452
  hand-corrected boxes + 85 background negatives (pseudo-labels generated by the base detector, then
  corrected in CVAT by the author; night fire excluded).
- **Compute**: on-demand L4 on GCP (`infra/`), 40 epochs @1280, ~18 min, ~$0.35.
- **Whole-fire holdout**: the 6 recent CA `EVAL_FIRES` (2024–2025) are never in training — the model
  is only ever tested on fires whose towers and events it never saw.

In-sample training-set validation reached mAP50 0.938 — expected for in-distribution data and *not*
the result that matters; the held-out eval below is.

## Held-out eval — before vs after fine-tuning

Same leak-safe TTD harness ([ttd-findings.md](ttd-findings.md)), run `--eval-only` on the 6 held-out
fires, scoring the *exact base model Phase C started from* vs the fine-tuned model — so fine-tuning is
the only variable. At the 5% pre-ignition false-alarm target, leave-one-fire-out:

| fire | base (`gcp_grouped_1280`) | Phase C |
|---|---|---|
| Vista (2024) | miss | miss |
| Tenaja (2024) | det 4.0 min | det 17.0 min |
| Bahrman (2024) | det 2.9 min | det 0.9 min |
| Palisades (2025) | det 0.0 min | det 4.0 min |
| Highway (2025) | det 10.0 min | det 8.0 min |
| **Coches (2025)** | **miss** | **det 17.0 min** ← rescued |
| **detection rate** | **4/6 (67%)** | **5/6 (83%)** |
| **held-out pre-ignition FA** | **16.7%** | **7.1%** |

**Phase C dominates the base at this operating point**: it detects *more* fires (5/6 vs 4/6, Coches
rescued) while *more than halving* the false-alarm rate (16.7% → 7.1%). The base's faster median TTD
(3.4 vs 8.0 min) is bought with 2.4× the false alarms — not a fair trade; matched-FA would favour
Phase C further. The sharpest signal is calibration: a threshold set on 5 fires transfers to the 6th
far better after fine-tuning (7.1% vs 16.7% achieved FA), i.e. the model behaves *consistently* across
unseen recent fires — that consistency is the distribution shift closing.

## Correcting the recent-CA framing

Earlier writeups said the zero-shot detector "misses Palisades, Coches, Tenaja entirely." That was
the **proof-scale** `grouped_proof` model. The **full-scale** base (`gcp_grouped_1280`, Phase C's
actual starting point) already detects **Palisades and Tenaja** — so part of the original "recent
miss" was a proof-scale artifact, not pure distribution shift. Phase C's specific, honest additions
over its own base are: **Coches rescued** and the **false-alarm rate more than halved**. Vista (2024)
is still missed by both and is the remaining hard case.

## Motion generalizes to the held-out fires

The [horizon-anchored motion](motion-findings.md) cue, measured standalone on the 6 held-out fires:
per-fire `anchored_change` AUC **0.742 [0.648, 0.850]** (CI excludes 0.5), floating-change control
**0.554** (near chance) — so anchored motion **separates onset on recent CA fires it was never tuned
on**, a touch stronger than on the training fires (0.708). It beats the now-strong Phase C confidence
in only 2/6 fires (mean lift +0.05) — the fine-tuned appearance detector narrows the gap — but the
naive fusion (0.756) edging both single signals suggests residual complementarity worth a learned
temporal head.

## Caveats

- **n = 6.** Detection-rate 90% CI is [50%, 100%]; read the direction, not the point value.
- **Pseudo-labels.** Training boxes were detector-proposed then hand-corrected by the author (a career
  wildland-fire professional); they are not independent ground truth.
- **Training-set val is in-sample.** The 0.938 mAP50 is on training fires; only the held-out eval is a
  fair measure.

## Reproduce

```bash
# features for the 6 held-out fires, before and after fine-tuning (tiled @640, native-res crops)
python src/models/figlib_tiled.py --eval-only --weights runs/gcp_grouped_1280/weights/best.pt --out features_evalfires_base.npz
python src/models/figlib_tiled.py --eval-only --weights runs/figlib_phaseC/weights/best.pt   --out features_evalfires_phaseC.npz
# TTD on the held-out fires, before vs after
python src/models/figlib_ttd.py --eval-only --features data/figlib/features_evalfires_base.npz   --tag _evalbase
python src/models/figlib_ttd.py --eval-only --features data/figlib/features_evalfires_phaseC.npz --tag _evalphaseC
# motion separability on the held-out fires
python src/models/figlib_ttd.py --eval-only --motion --features data/figlib/features_evalfires_phaseC.npz \
  --motion-cache data/figlib/motion_feats_eval.npz --tag _evalmotion
```
